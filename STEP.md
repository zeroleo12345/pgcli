## set dockerhub token and publish image
1. create dockerhub token at https://app.docker.com/accounts/zeroleo12345/settings/personal-access-tokens
2. add dockerhub token at https://github.com/zeroleo12345/pgcli/settings/secrets/actions
3. no need create repo manually
4. manually trigger CI or git push tags
5. CI create image repo and publish image automatically
6. check dockerhub repo at https://hub.docker.com/repositories/zeroleo12345
